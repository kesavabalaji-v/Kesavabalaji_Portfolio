## 📖 About

My personal portfolio website — a premium light-theme, fully responsive single-page site built with **pure HTML, CSS, and vanilla JavaScript**. No frameworks, no build step, no dependencies. Every animation is written from scratch.

It showcases my work as a Full Stack Developer: real client delivery, full stack applications with machine learning, and my continuous learning journey.

## ✨ Features

| Feature | Description |
|---|---|
| ⌨️ **Typing animation** | Rotating role headline built with vanilla JS |
| 📊 **Coding scoreboard** | Animated count-up stats (LeetCode, certifications, projects) |
| 🎞️ **Scroll reveal** | Sections fade in on scroll using IntersectionObserver |
